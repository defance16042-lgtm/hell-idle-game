# 平行三國武將逐格攻擊分鏡

董卓維持既有八張角色攻擊影格與原本的赤金攻擊效果，不在這次變更中改動。李儒、樊稠、張濟、呂布則改成全新的 PNG 圖片逐格演出：角色動作影格與飛斬／能量波影格分開製作，播放時只切換圖片來源並移動透明圖片覆層，不以 Canvas 即時繪製攻擊光效，也不再使用舊的 CSS keyframe 或前衝式 Canvas 動作。

四位將軍各有六張角色圖與六張透明攻擊效果圖。每位的六段節奏依序為預備、蓄勢、起招、出招、完整收勢、回復守勢。動畫只改變視覺，不改戰鬥命中判定、技能或傷害結算。素材均位於 `assets/monsters/parallel_three_kingdoms/`，由 `scripts/parallel-three-generals-frame-attacks.js` 共用 `playParallelThreeKingdomsBossAttackStoryboard` 入口播放。

| 角色 | 出招分鏡 | 專屬效果 |
| --- | --- | --- |
| 李儒 | 舉起毒珠、聚毒、向左施放、收招回守 | 紫綠毒霧包裹藍白與金色弧形毒波 |
| 樊稠將軍 | 拉回長柄武器、抬起蓄勢、雙手斜向重斬、回復守勢 | 赤金重斬月牙與藍白內緣，帶火星與衝擊 |
| 張濟將軍 | 槍尖凝光、轉肩瞄準、向左突刺、收槍回守 | 青玉藍白長槍波；素材在播放時水平翻轉，以符合敵人由右向左出招 |
| 呂布 | 馬上舉起方天戟、蓄勢、揮出重斬、戰馬落地回守 | 赤紫雙月牙與藍白刀心、金色火星 |

正常演出約 730–825ms。系統偏好減少動態時仍保留全部六個辨識影格，總時長約 680ms。PNG 影格使用共同尺寸與固定錨點，避免切圖播放時角色忽大忽小或跳位；攻擊結束或被下一次攻擊取代時，會移除覆層並還原原始角色圖。
