# 平行三國三將 Canvas 攻擊分鏡

本分鏡由 Canvas 2D 與 `requestAnimationFrame` 即時繪製，不使用 CSS keyframes。舞台覆層以 `#battle-stage` 為座標系，角色精靈在分鏡期間暫時隱藏，Canvas 以原圖繪製姿勢位移；攻擊光跡、飛行物、命中爆發與粒子也都由 Canvas 繪製。動畫結束後恢復原始精靈樣式，戰鬥命中／傷害計算照舊。

董卓、呂布與李儒共用 `playParallelThreeKingdomsBossAttackStoryboard` 動態分鏡入口，按角色使用各自的攻擊表現；董卓保留逐格身體動作與赤金刀氣，呂布使用赤紫方天斬，李儒使用紫燼毒霧。呂布舊 CSS keyframes 分鏡與舊版專用呼叫路徑已移除。

## 角色設計

| 角色 | 節奏（約 0.94 秒） | 自創攻擊表現 |
| --- | --- | --- |
| 李儒 | 0–0.28 蓄毒；0.20–0.82 發射；0.72–1.00 命中 | 紫色毒能在身前聚成旋渦，帶弧線的魘霧毒彈飛向玩家，命中後綻開紫綠毒霧與毒星。怪物姿勢微微後仰施法。 |
| 呂布 | 0–0.28 蓄勢；0.20–0.82 揮斬；0.74–1.00 命中 | 怪物原圖同步前衝、抬身，赤紫方天月牙斬沿戰場飛出，命中時展開紫紅衝擊環與碎光。 |
| 張濟將軍 | 0–0.32 槍尖凝光；0.24–0.74 突刺；0.68–1.00 命中 | 青玉符光聚到槍尖，長槍影沿怪物至玩家的方向快速刺出，命中時形成雙層玉環與碎光。怪物圖像同步前傾、突進。 |
| 樊稠將軍 | 約 0.72 秒；短暫蓄勢、一次橫向揮砍、回到待機 | 樊稠身體輕微後帶再向前揮砍，伴隨一道簡潔的橙金色弧形刀光；不做連擊、巨大刀氣、震盪環或大量粒子。 |

`prefers-reduced-motion` 等級目前沿用 Canvas 時長和軌跡；若需要支援低動態偏好，應另外縮短時間與減少粒子數量，不需更改戰鬥結算。

## 神龍套裝特效隔離

金色盤龍與深空覺醒光環移至 `#battle-stage` 內的 `#shenlong-aura-overlay`，不再是 `#player-icon` 的子元素。覆層透過 `requestAnimationFrame` 讀取玩家圖示中心點來更新位置，使用未變形的 `offsetWidth/offsetHeight` 作為尺寸；旋轉、呼吸和浮動只作用於覆層中的光環本身，因此不會繼承攻擊分鏡的角色旋轉／縮放。攻擊移動期間仍會跟隨角色中心定位，但光環不被角色姿勢帶著轉動。
