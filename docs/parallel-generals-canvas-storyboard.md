# 平行三國將軍 Canvas 攻擊演出

董卓保留八張逐格角色影格與赤金 Canvas 刀氣。李儒、樊稠、張濟、呂布的舊 CSS keyframes／pseudo-element 分鏡與舊 wrapper 已移除；新攻擊由 Canvas 2D、`requestAnimationFrame` 和可復原的角色姿勢位移全新繪製。角色原圖保留，攻擊光跡、飛行武器／能量、命中環與火花在 `#battle-stage` 座標中即時繪製。動畫只改變外觀，不改戰鬥命中與傷害結算。

五位首領共用 `playParallelThreeKingdomsBossAttackStoryboard` 入口，按角色選擇獨立攻擊 profile。四位新 Canvas 演出結束後會還原角色原本的 inline transform／filter 樣式。

## 角色設計

| 角色 | 節奏 | 全新攻擊表現 |
| --- | --- | --- |
| 李儒 | 約 1.02 秒；聚能、毒彈弧飛、命中 | 身體後仰聚出紫綠毒旋，魘霧毒彈沿弧線飛向玩家，命中綻開毒環與毒星。 |
| 樊稠將軍 | 約 0.90 秒；蓄勢、單次重斬、命中 | 身體先後帶再前衝，橙金弧刃帶火星直切玩家，命中出現金紅環；不做連擊。 |
| 張濟將軍 | 約 0.88 秒；槍尖凝光、直線突刺、命中 | 身體前傾突進，青玉長槍光痕與兩道窄尾流刺向玩家，命中展開雙層玉環。 |
| 呂布 | 約 1.08 秒；赤紫蓄勢、方天重劈、命中 | 前衝抬身，赤紫雙層方天月牙沿戰場飛出，命中爆出紫紅衝擊環與碎光。 |

`prefers-reduced-motion` 下四位新演出縮短為原時長的 70%（最低 680ms），仍保留可辨識的蓄勢、出招與命中提示。所有 Canvas 和角色樣式在動畫結束或下一次攻擊開始時清理／還原。

## 神龍套裝特效隔離

金色盤龍與深空覺醒光環移至 `#battle-stage` 內的 `#shenlong-aura-overlay`，不再是 `#player-icon` 的子元素。覆層透過 `requestAnimationFrame` 讀取玩家圖示中心點來更新位置，使用未變形的 `offsetWidth/offsetHeight` 作為尺寸；旋轉、呼吸和浮動只作用於覆層中的光環本身，因此不會繼承攻擊分鏡的角色旋轉／縮放。攻擊移動期間仍會跟隨角色中心定位，但光環不被角色姿勢帶著轉動。
